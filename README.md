# dsh-skill-portfolio

Навык DeepSeek Harness для личного дашборда инвестиционного портфеля. Плагин
поставляет сам навык: инструкции, движок сборки, шаблон страницы, примеры и
проверки. Данные человека он не содержит и никуда не отправляет.

## Что даёт

После установки в каталоге навыков появляется `portfolio`. Дальше достаточно
попросить агента:

- «настрой мой портфель» / «сделай дашборд по моим брокерам»;
- «подключи Т-Инвестиции», «разбери отчёт БКС / Сбера»;
- «обнови портфель, вот новая выгрузка»;
- «добавь в дашборд вкладку, график или цель».

Навык собирает страницу в папке человека: стоимость, прибыль, XIRR, сравнение
с индексом Мосбиржи, состав по бумагам и отраслям, дивиденды и купоны, прогноз
выплат и ленту операций. Цены подтягиваются с Мосбиржи, курсы — с ЦБ.

## Установка

Репозиторий: <https://github.com/PiedPiperMoney/dsh-skill-portfolio>.

### Из GitHub (основной способ)

1. Откройте **Plugins** в боковой панели.
2. **Add plugin** → вставьте `github:PiedPiperMoney/dsh-skill-portfolio` →
   **Install**.
3. Нажмите **Enable now**.

Или командой, если `dsh` доступен в PATH:

```bash
dsh plugin --profile web add github:PiedPiperMoney/dsh-skill-portfolio
```

Версию можно закрепить тегом:

```bash
dsh plugin --profile web add github:PiedPiperMoney/dsh-skill-portfolio#v0.1.1
```

### Из npm

Если пакет опубликован в npm:

```bash
dsh plugin --profile web add dsh-skill-portfolio
```

Плагин появится у всех сессий этого профиля. Новая сессия сразу увидит навык
`portfolio`; в текущей может понадобиться начать новый чат.

## Обновление

Плагины DSH **не обновляются сами**. Новая версия ставится поверх старой:

- в интерфейсе: **Plugins** → карточка плагина → удалить → **Add plugin** →
  `github:PiedPiperMoney/dsh-skill-portfolio#v0.2.0`;
- командой:

```bash
dsh plugin --profile web add github:PiedPiperMoney/dsh-skill-portfolio#v0.2.0
```

Версия видна на карточке плагина. Перед обновлением полезно прочитать
[CHANGELOG.md](CHANGELOG.md): там отмечено, меняется ли формат `settings.json`.

## Если навык уже стоял вручную

Ручная копия в `~/.dsh/skills/portfolio` имеет приоритет выше плагина, поэтому
старые инструкции продолжат использоваться. Уберите её из каталога навыков:

```bash
mv ~/.dsh/skills/portfolio ~/.dsh/skills/portfolio.backup
```

Плагин при запуске пишет предупреждение, если находит такую копию. Рабочую
папку с портфелем (`~/Мой портфель` или любую другую) это не затрагивает:
`settings.json`, отчёты, `dashboard-data.js` и ваши `custom.js` / `custom.css`
остаются на месте.

## Требования

- DSH с менеджером плагинов (Web-профиль).
- Node.js 18 или новее на машине — движок навыка запускается через `node`.
- Интернет для цен Мосбиржи и курсов ЦБ. Т-Инвестиции дополнительно требуют
  токен **только на чтение**.

## Данные и приватность

Плагин не собирает и не передаёт личные данные. Отчёты брокеров, `settings.json`,
токен Т-Инвестиций и собранные файлы остаются в папке человека. Наружу уходят
только запросы цен и индексов к Мосбирже, курсов к ЦБ и — если подключены
Т-Инвестиции — запросы к API Т-Банка с токеном владельца. Собранная страница
дополнительно грузит шрифты Google Fonts, без данных человека.

Плагин выполняет только регистрацию навыка. Код самого навыка лежит в
`assets/portfolio/` и остаётся читаемым: его можно проверить и запустить вручную.

## Что внутри

```
assets/portfolio/       навык целиком: SKILL.md, references/, engine/, dashboard/,
                        sample/, tests/
lib/index.js            регистрация навыка в реестре DSH
cordis.patch.yml        строка плагина в композиции профиля
test/provider.test.mjs  проверка пакета и ресурсов
scripts/check-skill.mjs прогон штатных проверок навыка
scripts/release.mjs     версия, тесты, tarball
```

## Разработка

```bash
npm test           # проверки пакета + штатные проверки навыка
npm pack --dry-run # состав публикуемого пакета
```

Обновить навык в пакете:

```bash
node scripts/sync-skill.mjs                 # из ../portfolio-skill/skills/portfolio
node scripts/sync-skill.mjs /путь/к/навыку  # из другой папки
```

Источник навыка — открытый репозиторий [portfolio-skill](https://github.com/PiedPiperMoney/portfolio-skill),
склонированный рядом. Скрипт заменяет `assets/portfolio/` его копией. Дальше — `npm test`.
Политика версий:

- **patch** — исправления разбора отчётов, текста и мелкие ошибки;
- **minor** — новый источник, раздел страницы, настройка;
- **major** — несовместимое изменение `settings.json` или структуры папки.

Релиз:

```bash
node scripts/release.mjs patch   # или minor / major / 1.2.3
git add -A && git commit -m "v0.1.1" && git tag v0.1.1
git push --follow-tags
gh release create v0.1.1 ./dsh-skill-portfolio-0.1.1.tgz
```

`release.mjs` поднимает версию, гоняет `npm test`, собирает tarball и печатает
команды публикации. Сам он ничего не публикует. Если пакет нужен и в npm —
дополнительно `npm publish`.

## Удаление

**Plugins** → карточка плагина → удалить. Или:

```bash
dsh plugin --profile web remove dsh-skill-portfolio
```

Папки с портфелями и собранные дашборды при этом не удаляются.
